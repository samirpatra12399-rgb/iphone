# 📱 iPhone 16 Pro iOS Notification & Auto-Conversation Simulator

An ultra-realistic, interactive simulator of the iPhone 16 Pro Lock Screen and iOS 18 Notification Center with Dynamic Island animations, Telegram integration, 30 realistic profile avatars, English-to-Thai auto-translation, and an automated virtual keyboard typing engine.

---

## ✨ Features

- **📲 Dual Display Mode**:
  - **Edge-to-Edge Fullscreen Mobile**: Fits 100% of any smartphone screen with zero borders (`100dvh`).
  - **Titanium Chassis Frame**: High-fidelity iPhone 16 Pro titanium frame with physical side buttons and glare reflections.
- **⚡ Full End-to-End Conversation Automation**:
  - One-click automated conversation scenario:
    1. **10-Second Timer**: Countdown badge so you can start your screen recording.
    2. **Incoming Message**: iOS Tri-Tone chime rings, Dynamic Island expands, and notification lands on the lock screen.
    3. **Natural Reading Pause**: 2.2-second pause simulating reading time.
    4. **Automated Virtual Keyboard Reply**: Keyboard slides up, keys light up character-by-character with mechanical clicks, typing in Thai.
    5. **Delivered**: Outgoing message swoosh plays, delivered checkmark (`✓✓`) appears, and keyboard slides down.
- **⌨️ Authentic iOS Virtual Keyboard (`IOSKeyboard`)**:
  - Full **Thai Keyboard Layout (แป้นพิมพ์ภาษาไทย)** with authentic Thai keys, spacebar (`วรรค`), send button (`ส่ง`), and Thai quick suggestion pills.
  - English QWERTY layout with 1-tap `🌐` globe toggle.
  - Mechanical click audio for every key.
- **🇹🇭 Real-Time English-to-Thai Auto-Translation**:
  - Type in English, and it automatically converts into natural Thai script (ภาษาไทย) in real time.
- **✈️ Telegram Integration & 30 Realistic Avatars**:
  - Official Telegram icons and `#229ED9` branding.
  - 30 curated high-resolution portrait avatars (*#1 Best Pick Ananya*, women, men, aesthetic) + custom image upload.
- **🔔 Authentic iOS Web Audio Synthesizer**:
  - 5 synthesized iOS alert tones: *Tri-Tone*, *Chord*, *Aurora*, *Popcorn*, *Note*.
  - Mechanical keyboard clicks, lock sound, and outgoing message swoosh.
- **🛡️ 100% Clean Screen (Zero Fake Buttons)**:
  - All developer controls, timers, and settings are housed in a **SEPARATE** Control Panel so screenshots and screen recordings look 100% genuine.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
npm run preview
```
